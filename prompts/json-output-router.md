# 输出格式（JSON 模式）

把评审计划以 JSON 格式输出，只输出 JSON 本身（不要 markdown 代码块包裹，不要解释文字）。

形状（字段名、类型完全一致，不增删字段）：

{"focusAreas": [{"area": "重点领域名称", "files": ["涉及的文件路径，从仓库文件树原样复制"], "why": "为什么该领域值得重点关注"}], "riskAreas": [{"area": "风险面名称", "why": "风险说明"}], "readPaths": ["建议主评审深读的仓库文件路径"], "strategy": "本次评审的整体策略（一句话）"}
